How to use the SQL Mystery Console

1. Run a query

Type a SQL statement in the editor and click Run Query (or use List Tables to quickly see everything in the database). Results appear in the panel below.

2. Save a query

Write a query, give it a name in the Name this query... field, then click Save Query. Saved queries are stored in your browser (localStorage) so they persist between visits.

3. Load a saved query

Pick a saved query from the Saved queries... dropdown, then click Load to place it back in the editor. You can also click Delete to remove a saved query you no longer need.

4. Reset the database

Click Reset DB to wipe all changes and reload the database fresh, in case you want to start your investigation over.

5. Browse clues

Use Previous clue / Next clue (or the ←/→ arrow keys) to page through evidence images in the Clues Folder Viewer.

6. Name the killer

Once you've pieced the clues together, type the suspect's name in the Name the Killer section and click Submit Accusation. You'll be told right away if you cracked the case or need to keep investigating.
