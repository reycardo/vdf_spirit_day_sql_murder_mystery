# Clues Folder

Put your clue images in this folder, for example:

- clue-01.png
- clue-02.jpg
- clue-03.webp

Then list them in manifest.json in the order players should see them.

Example manifest.json:

{
  "images": [
    {
      "file": "clue-01.png",
      "title": "Trophy Room Floor",
      "description": "A small stain next to a broken display case."
    },
    {
      "file": "clue-02.jpg",
      "title": "Trade Window",
      "description": "A screenshot showing the dagger trade."
    }
  ]
}
